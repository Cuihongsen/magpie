# 渠道商疯狂重试实施计划

**目标：** 在个人 Magpie fork 提供渠道级开关和可配置重试次数，默认 20 次。

**设计：** [渠道商疯狂重试](../specs/2026-11-10-crazy-retry-design.md)。

1. 在 provider、CLI 和 GUI 中保存开关与次数，并测试旧配置和输入校验。
2. 以假上游编写失败测试，在原生路由内实现有界 429 重试和正常降级。
3. 验证流、取消、Retry-After、并发及既有 combined-token 恢复。
4. 从已审查的代码构建、签名和隔离验收，提交并推送 fork。
5. 用 Magpie 原生交接部署，核对运行进程和实际渠道设置。
